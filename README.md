# MAD1-project-trekking-management-system
I am uploding my MAD 1 project of my IITM BS degree course here.

Trekking Management System is a role-based web application built with Flask, SQLite, Jinja2, and Bootstrap for managing trekking activities. The system enables Admins to manage treks, approve and assign staff, and monitor bookings, Trek Staff to manage assigned treks and participants, and Users (Trekkers) to browse, search, and book treks. It includes authentication, booking management, trek tracking, overbooking prevention, and role-based access control to streamline the entire trekking management process.
The tools used for this project:
Python
Flask
Jinja2
HTML5
CSS3
Bootstrap
SQLite
